# Royal SpecBoard 設計師規格工作臺

*A collaborative project by roylin1003 and Claude.*

單檔網頁版面規格工作臺。在畫布上拖出矩形版面，工程量尺即時標注尺寸與四向間距，
**每個數字都可以直接點下去改**；整張版面同步成一段規格文字（DSL）——
人看得懂、程式吃得下、AI 讀得通。要交出去的，就是那段字。

**▶ 立即使用**：<https://royal-specboard.roylin1003.workers.dev/>

> 目前為 **alpha**，格式與功能仍在演化中。歡迎開 Issue 回報與提案。

---

## 為什麼做這個

版面溝通的老問題：設計者說「看起來偏了」，工程師問「偏幾 px」，AI 兩邊都聽不見。
Royal SpecBoard 讓三方坐同一張桌子——

- **設計者**用眼睛與滑鼠：拖曳、吸附、對齊分布，不必看見任何座標
- **工程**用數字：選取任何元件，寬高、鄰距、邊距全部標出來，點了就能改
- **AI** 用規格文字：整張版面就是一段 DSL，貼進任何 LLM 對話就是施工單

操作即宣告：你拖到吸附，數字就寫好了；你改一個數字，畫布就動了；文字框永遠與畫布同步。

## 快速開始

下載後**雙擊 `index.html` 就能用**（file:// 直開，零安裝、零建置、零相依）。

只有「載入工作臺目前版面」走 `fetch`，需要一個本機伺服器：

```bash
python -m http.server 8000
```

然後開 `http://localhost:8000/`。「載入規格檔」走瀏覽器原生的檔案選擇器（可多選），
任何位置、file:// 直開、線上版都能用。

版面每動一次就自動存進瀏覽器（localStorage），關掉再開還在；「下載 .spec.txt」把規格存成檔。
標題旁的 ● 表示「上次下載／匯出之後有改動」。

**圖即規格**：「匯出 PNG（含規格）」輸出 1:1 的畫布圖，規格文字藏在 PNG 的 tEXt 區塊裡——
那張圖貼到哪裡都帶著完整規格，**拖回工作臺就重建**。規格檔或 PNG 都可以直接拖放到畫布上載入。

## DSL 一分鐘上手

```
// 以 // 開頭的行是註解
#canvas w=2560 h=1440 bg=#0E1116 grid=8
rect id=nav x=0 y=0 w=2560 h=96 fill=#171C22
rect id=cta x=160 y=660 w=320 h=96 fill=#4CC3D9 r=48 body="開始閱讀" size=36 color=#0E1116 align=center valign=middle
```

一行一件，屬性依序：位置尺寸、`fill` 底色（`none` 為透明）、`stroke` 框線、`r` 圓角、
`op` 透明度、`body` 文字（換行寫 `\n`）與字級／字色／對齊。

它是有效的 AI 交換格式：把這段字貼給任何 LLM，它讀得懂你的版面；
請它回一段 DSL，貼進「套用文字」，你就看得見它的提案。

## 實況擷取器

`snapshot-capture.js`——把**任何跑著的網頁**抄成 DSL：
開那個頁面的 DevTools console，整檔貼上按 Enter，規格文字就進了剪貼簿。
拿真實專案的現況進工作臺診斷、標注、改版，這是第一步。

`samples/` 附兩份擷取範例，下載 repo 後用「載入規格檔」開即可。

## 操作

| 操作 | 功能 |
|---|---|
| 拖曳 | 移動（自動吸附格線與其他元件） |
| Shift＋點選 | 加減選取；空白處拖曳＝框選 |
| 方向鍵 | 微調 1px（Shift ×10） |
| D | 複製選取元件 |
| Esc | 取消選取 |
| Ctrl+Z／Ctrl+Shift+Z | 復原／重做 |
| 點量尺數字 | 原地改值（間距數字＝移動元件） |
| 拖放檔案到畫布 | 載入 .spec.txt／.png（含規格） |

## 參與開發

歡迎程式設計師加入——這個 repo 的參與門檻刻意壓到最低：
單一 HTML 檔、無框架、無建置、clone 下來改完重整就看得到。

- **Issue**：bug、需求、設計討論都收
- **Pull Request**：直接改 `index.html` 送過來
- **用 DSL 提案**：要建議 UI 改動，可以直接在工作臺裡畫好、貼譜面到 Issue——
  這個工具自己的輸出格式就是它的提案格式

### Roadmap

- **多頁規格**：一份 DSL 含桌機＋手機兩張畫布，同 id 元件跨頁聯動選取、輸出映射報告
- **分頁**：一個工作臺管多張畫布
- **約束詞彙**：DSL 記「吸附／等寬／貼邊」等關係，不只記座標
